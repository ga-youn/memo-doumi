메모도우미 (Memo Doumi) 0.1.0
==============

실행
  MemoDoumi.exe 를 더블클릭하면 작업표시줄 위에 강아지가 나타납니다.
  설치 과정은 없습니다. 이 폴더를 원하는 곳에 두고 쓰면 됩니다.
  (sprites 폴더는 exe 와 같은 곳에 있어야 강아지 그림이 나옵니다)
  (fonts 폴더의 Pretendard 글꼴로 표시합니다. 폴더가 없으면 맑은 고딕으로 나옵니다. PC 에 글꼴을 설치하지는 않습니다)

기본 사용법
  강아지 클릭        말풍선(메모) 열기 / 닫기
  강아지 우클릭      메뉴: 새 메모, 메모 검색, 돌아다니기, Windows 시작 시 자동 실행, 종료
  강아지 드래그      위치 옮기기 (말풍선도 따라옵니다)

말풍선
  강아지 위에는 메모가 한 번에 하나만 뜹니다.
  위쪽 줄    +  새 메모 / 돋보기  검색 / 색 / 핀  고정 / 휴지통  삭제 / X  닫기
  서식 줄    굵게 / 기울임 / 밑줄 / 취소선 / 글머리 목록 — 오른쪽 끝에 마지막으로 고친 시각 (마우스를 올리면 등록·수정 시각)
  아래쪽 줄  |<  처음 /  <  이전 /  3 / 12  지금 번호와 전체 개수 /  >  다음 /  >|  마지막
  핀으로 고정한 메모는 말풍선에서 떨어져 나와, 끌어다 놓은 자리에 계속 떠 있습니다.
  X 와 Esc 는 숨기기만 합니다. 메모는 지워지지 않습니다.
  휴지통으로 보던 메모를 지우면 말풍선이 닫히지 않고 바로 앞 순서의 메모가 나옵니다.
  메모 안의 링크는 http, https 로 시작하는 웹 주소만 열립니다.
  파일 경로, 네트워크 공유(\\서버\...), 실행 파일, 그 밖의 주소는 눌러도 열리지 않습니다.

검색
  돋보기 버튼, 강아지 우클릭 메뉴, 또는 Ctrl+Alt+F 로 엽니다.
  말풍선이 하나 더 뜨지 않고, 보던 말풍선 자리에서 내용만 목록으로 바뀝니다.
  왼쪽 위 ← 버튼이나 Esc 를 누르면 보던 메모로 돌아갑니다.
  글자를 입력하면 모든 메모의 내용에서 찾습니다. 비워 두면 전체 메모 목록입니다.
  방향키로 고르고 Enter (또는 클릭) 하면 그 메모가 열립니다.

단축키
  Ctrl+Alt+N   새 메모            Ctrl+Alt+M   말풍선 보이기 / 숨기기
  Ctrl+Alt+F   메모 검색
  메모 안에서:  Ctrl+N 새 메모 / Ctrl+F 검색 / Alt+← → 이전·다음 / Alt+Home End 처음·마지막 / Esc 숨기기
  서식:         Ctrl+B 굵게 / Ctrl+I 기울임 / Ctrl+U 밑줄 / Ctrl+T 취소선 / Ctrl+Shift+L 목록

메모가 저장되는 곳
  이 폴더 안의 data 폴더
    data\notes\제목-번호.md   메모 하나당 파일 하나 (메모장이나 다른 편집기로 열 수 있습니다)
                              서식은 마크다운으로 저장됩니다: **굵게** *기울임* ~~취소선~~ <u>밑줄</u> - 목록
    data\settings.json        강아지 위치 같은 설정
    data\trash\               휴지통 버튼으로 지운 메모 (직접 비우기 전까지 남습니다)
    data\originals\           직접 넣은 파일을 앱 형식으로 바꾸기 전에 남긴 원본 (직접 비우기 전까지 남습니다)
    data\error.log            저장 실패나 읽지 못한 파일 같은 문제의 기록
  메모는 암호화하지 않은 글자 그대로 저장됩니다. 이 폴더를 볼 수 있는 사람과 프로그램은 메모를 읽을 수 있으므로
  비밀번호 같은 것은 적어 두지 마세요. 지운 메모(trash), 바꾸기 전 원본(originals), 예전 형식의 원본(notes.json.migrated)도 글자 그대로 남습니다.
  프로그램과 메모가 한 폴더에 있습니다. 폴더를 통째로 옮기면 메모도 같이 옮겨지고,
  폴더를 지우면 메모도 지워집니다. 백업은 data 폴더만 복사하면 됩니다.
  이 폴더를 다른 사람에게 줄 때는 data 폴더를 빼고 주세요.
  notes 폴더에 .md 파일을 넣으면 앱이 켜져 있어도 몇 초 안에 새 메모로 읽어 들입니다 (다시 켤 필요 없음).
  이미 읽어 들인 메모 파일을 바깥에서 고칠 때는 먼저 앱을 종료하세요.
  1MB 가 넘거나 글자 파일이 아닌 .md 는 읽지 않고 그대로 둡니다. 시작할 때 알림 창으로 알려 줍니다.
  앱이 켜져 있는 동안 파일을 직접 고치면 반영되지 않습니다. 고칠 때는 앱을 끄고 하세요.
  (Program Files 처럼 쓰기가 막힌 곳에 두면 %APPDATA%\MemoDoumi 에 대신 저장됩니다)

저장이 안 될 때
  디스크가 가득 찼거나 폴더에 쓸 수 없으면 화면 오른쪽 아래에 알림 창이 뜹니다.
  바뀐 내용은 앱이 켜져 있는 동안 보관하며 자동으로 다시 저장을 시도합니다. "다시 저장" 을 눌러 바로 시도할 수도 있습니다.
  저장이 안 된 상태로 종료하려 하면 한 번 더 물어봅니다.

예전 버전(MemoHelper)에서 올 때
  %APPDATA%\MemoHelper 의 메모를 처음 한 번 복사해 옵니다. 원래 폴더는 지우지 않습니다.
  잘 옮겨졌는지 확인한 뒤 필요 없으면 직접 지우세요.

필요 환경
  Windows 10 / 11 (.NET Framework 4.8 — Windows 에 기본 포함)

업데이트할 때
  MemoDoumi.exe --quit 을 실행하면 떠 있는 앱이 저장하고 끝납니다. 그 뒤에 파일을 덮어쓰세요.
  (data 폴더는 그대로 두면 메모가 유지됩니다)
  공개 전 개발판에서 만든 메모가 있으면 처음 실행할 때 메모 파일 이름의 번호가 8자에서 32자로 바뀝니다. 내용은 그대로입니다.

완전히 지우려면
  1) 강아지 우클릭 > "Windows 시작 시 자동 실행" 체크 해제 > 종료
  2) 이 폴더 삭제 (메모도 함께 지워집니다)
