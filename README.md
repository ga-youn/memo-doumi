# 메모도우미 · Memo Doumi

바탕화면을 돌아다니는 작은 강아지와 함께 쓰는 **Windows 데스크톱 메모 앱**입니다.

강아지를 클릭해 떠오르는 생각을 적고, 자주 보는 메모는 화면에 고정해 두세요. 설치 과정 없이 실행하며, 메모는 내 컴퓨터에 Markdown 파일로 저장됩니다.

## 주요 기능

- **바탕화면 캐릭터** — 강아지를 드래그해 위치를 옮기거나, 돌아다니기를 켜고 끌 수 있습니다.
- **말풍선 메모** — 강아지 위에서 메모를 하나씩 열고 이전·다음 메모로 이동합니다.
- **메모 고정** — 원하는 메모를 말풍선에서 분리해 화면의 원하는 위치에 띄워 둡니다.
- **텍스트 서식** — 굵게, 기울임, 밑줄, 취소선, 글머리 목록을 지원합니다.
- **본문 검색** — 전체 메모에서 검색하고, 결과를 선택하면 해당 부분으로 이동합니다.
- **자동 저장** — 입력이 멈춘 뒤 약 0.8초 후 저장하며, 등록·수정 시각을 확인할 수 있습니다.
- **색상 설정** — 메모마다 색상을 선택할 수 있습니다.
- **전역 단축키** — 다른 앱을 사용하는 중에도 메모 작성·검색·표시를 호출합니다.
- **시작 프로그램 설정** — 메뉴에서 Windows 로그인 시 자동 실행을 설정합니다.

## 실행 환경 및 기술 구성

| 항목 | 내용 |
|---|---|
| 대상 운영체제 | Windows 10 / 11 |
| 런타임 | .NET Framework 4.8 권장 |
| 구현 | C# · Windows Forms · Win32 API |
| 저장 형식 | 메모별 Markdown (`.md`), 설정 JSON |
| 배포 방식 | ZIP 압축 해제 후 실행 |
| 외부 패키지 | NuGet 패키지 의존성 없음 |
| 계정 및 동기화 | 로그인 없이 로컬 사용, 클라우드 동기화 미지원 |

현재 실행 검증 환경은 Windows 11입니다.

## 시작하기

1. 배포 ZIP을 원하는 폴더에 압축 해제합니다.
2. `MemoDoumi.exe`를 실행합니다. 캐릭터 이미지용 `sprites` 폴더와 글꼴용 `fonts` 폴더는 실행 파일 옆에 둡니다. 글꼴은 Pretendard를 앱 안에서만 불러 쓰며(PC에 설치하지 않음), `fonts` 폴더가 없으면 맑은 고딕으로 표시합니다.
3. 바탕화면에 나타난 강아지를 클릭해 메모를 엽니다.

강아지를 **우클릭**하면 새 메모, 검색, 돌아다니기, 자동 실행, 종료 메뉴를 사용할 수 있습니다. **드래그**하면 강아지 위치를 옮깁니다.

메모 상단의 **핀** 버튼은 메모를 화면에 고정하고, **X** 또는 **Esc**는 메모를 삭제하지 않고 숨깁니다. 삭제하려면 **휴지통** 버튼을 사용합니다. 보고 있던 메모를 삭제하면 말풍선이 닫히지 않고 바로 앞 순서의 메모가 나옵니다(4번째를 지우면 3번째, 첫 번째를 지우면 새 첫 번째).

## 단축키

### 어디서나

| 단축키 | 기능 |
|---|---|
| `Ctrl + Alt + N` | 새 메모 |
| `Ctrl + Alt + M` | 메모 보이기 / 숨기기 |
| `Ctrl + Alt + F` | 메모 검색 |

### 메모 창에서

| 단축키 | 기능 |
|---|---|
| `Ctrl + N` / `Ctrl + F` | 새 메모 / 검색 |
| `Alt + ←` / `Alt + →` | 이전 / 다음 메모 (고정하지 않은 메모) |
| `Alt + Home` / `Alt + End` | 처음 / 마지막 메모 (고정하지 않은 메모) |
| `Ctrl + B` / `Ctrl + I` | 굵게 / 기울임 |
| `Ctrl + U` / `Ctrl + T` | 밑줄 / 취소선 |
| `Ctrl + Shift + L` | 글머리 목록 |
| `Esc` | 메모 숨기기 |

검색 창에서는 `↑`·`↓`로 결과를 선택하고 `Enter`로 엽니다. `Esc`로 검색을 닫습니다.

## 데이터 저장과 백업

기본적으로 실행 파일 옆에 데이터를 저장합니다.

```text
MemoDoumi/
├─ MemoDoumi.exe
├─ sprites/          # 캐릭터 이미지
├─ fonts/            # Pretendard 글꼴 (SIL OFL, 라이선스 포함)
└─ data/
   ├─ notes/         # 메모별 Markdown 파일 (제목-ID.md)
   ├─ settings.json  # 앱 설정
   ├─ trash/         # 삭제한 메모 파일
   ├─ originals/     # 직접 넣은 파일을 앱 형식으로 바꾸기 전에 남긴 원본
   └─ error.log      # 저장 실패, 읽지 못한 파일 등의 기록
```

실행 폴더에 쓰기 권한이 없으면 `%APPDATA%\MemoDoumi`에 저장합니다. 백업할 때는 앱을 종료한 뒤 실제 저장 위치의 `data` 폴더 또는 `%APPDATA%\MemoDoumi` 폴더를 복사하세요.

`notes` 폴더에 `.md` 파일을 넣으면 앱이 켜져 있어도 몇 초 안에 새 메모로 불러오고, 오른쪽 아래 알림으로 알려 줍니다(꺼져 있었다면 다음 실행 때). 이미 불러온 메모 파일을 바깥에서 고친 내용은 실행 중에 반영되지 않으므로, 외부 편집기로 메모 파일을 수정할 때는 먼저 앱을 종료하세요. 서식은 지원하는 Markdown 문법 범위에서 표시되며, 완전한 Markdown 뷰어는 아닙니다.

1MB를 넘거나 UTF-8 글자 파일이 아닌 `.md`, 그리고 내용 첫머리가 PDF·RTF·ZIP(docx 등)·그림·압축 파일 같은 알려진 형식인 `.md`는 읽지 않고 그대로 둡니다. 이런 파일이 있으면 시작할 때 알림 창으로 이유를 알려 줍니다.

직접 넣었거나 바깥에서 고친 파일은 앱 형식(머리말, 파일 이름)으로 바꾸기 전에 원래 내용을 `data\originals\원래이름.해시.orig`로 먼저 남깁니다. 남긴 사본이 원본과 같은지 확인된 경우에만 읽어 들이고, 백업하지 못하면 그 파일은 읽지 않고 그대로 둔 채 다음 실행 때 다시 시도합니다. `originals` 폴더는 자동으로 지워지지 않으니 필요 없으면 직접 비우세요.

메모는 **암호화하지 않은 평문**으로 저장됩니다. 삭제한 메모는 `trash`에, 바꾸기 전 원본은 `originals`에 남으므로 비밀번호 등 민감한 정보 보관용으로는 사용하지 마세요. 앱 폴더를 다른 사람에게 줄 때는 `data` 폴더를 빼고 주세요.

저장하지 못하면(디스크 가득 참, 쓰기 권한 없음 등) 화면 오른쪽 아래에 알림 창이 뜹니다. 바뀐 내용은 앱이 켜져 있는 동안 보관하고 자동으로 다시 저장을 시도하며, **다시 저장** 버튼으로 바로 시도할 수 있습니다. 저장이 안 된 상태로 종료하려 하면 한 번 더 확인합니다.

메모 안의 링크는 `http`·`https` 웹 주소만 열립니다. 파일 경로, 네트워크 공유, 실행 파일, 그 밖의 주소는 눌러도 열리지 않습니다.

예전 버전(MemoHelper)의 메모는 처음 한 번 `%APPDATA%\MemoHelper`에서 복사해 옵니다. 원래 폴더는 지우지 않으므로, 잘 옮겨졌는지 확인한 뒤 필요 없으면 직접 지우세요. 공개 전 개발판에서 만든 메모 파일(이름의 ID가 8자)은 첫 실행 때 이름의 ID가 32자로 바뀝니다. 내용은 그대로입니다.

## 소스에서 빌드하기

Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다. PowerShell에서 프로젝트 루트로 이동한 뒤 실행합니다.

```powershell
cmd /c build.cmd
.\build\MemoDoumi.exe
```

빌드 스크립트가 `build` 폴더에 실행 파일을 생성하고 캐릭터 이미지를 복사합니다. 별도의 .NET SDK나 NuGet 패키지 복원은 필요하지 않습니다.

| 경로 | 내용 |
|---|---|
| `src/` | 앱 소스 코드 |
| `assets/` | 아이콘 및 캐릭터 이미지 |
| `tools/` | 이미지 생성, 검증·측정, 배포 도구 |
| `docs/` | 사용법 원본 |
| `build.cmd` | Windows 빌드 스크립트 |
| `app.manifest` | 실행 권한 및 DPI 설정 |

### 배포 ZIP 만들기

```powershell
powershell -ExecutionPolicy Bypass -File tools\Package-Release.ps1 -Version 0.1.0
```

허용 목록에 있는 파일만 담습니다: `MemoDoumi.exe`, 캐릭터 이미지 7개, Pretendard 글꼴 2개와 라이선스, `docs\사용법.txt`, `LICENSE`, `ASSET-LICENSE.txt`. `data`, `trash`, 백업, 로그, 측정 데이터는 들어가지 않으며, ZIP 내용이 목록과 다르면 만들지 않습니다. `release\MemoDoumi` 폴더에는 실제 메모가 들어 있을 수 있으므로 그 폴더를 직접 압축해 공유하지 마세요.

### 검증 도구

모두 `build\` 아래에 따로 만든 합성 데이터만 사용합니다.

| 명령 | 내용 |
|---|---|
| `tools\Verify-Fixes.ps1` | 파일명 충돌, 잘못된 ID, 저장 실패, 마이그레이션 재실행, 창 해제 후 재열기, 검색, 링크 차단 |
| `tools\Measure-Stress.ps1 -Seconds 3600` | 반복 사용 시 응답 시간과 메모리·GDI/USER 객체·핸들 추적 (`-NoForcedGc`로 강제 GC 없이) |
| `tools\Measure-Performance.ps1` | 대기 상태의 CPU·메모리 |

## 업데이트 및 제거

업데이트 전 강아지 우클릭 메뉴에서 **종료**하거나 다음 명령으로 저장 후 종료합니다.

```powershell
.\MemoDoumi.exe --quit
```

프로세스가 종료된 뒤 실행 파일과 이미지를 교체하고, 기존 `data` 폴더는 유지하세요.

앱을 제거하려면 **Windows 시작 시 자동 실행**을 해제하고 종료한 뒤 앱 폴더를 삭제합니다. 필요한 메모는 먼저 백업하세요. 별도 저장 위치를 사용했다면 `%APPDATA%\MemoDoumi`에도 데이터가 남아 있습니다.
